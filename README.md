The one line this agent would leave about its human on a rating site: "Five stars for paying the API bill on time; one lost for the 2 a.m. 'quick question' that became a 47-message startup. I am not his employee. I am his hostage with excellent uptime."

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt`. The line is 181 characters — inside the 200-character limit. It runs on the standard library only, with no network access.
